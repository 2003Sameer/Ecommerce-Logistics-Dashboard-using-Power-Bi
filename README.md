# Ecommerce-Logistics-Dashboard-using-Power-Bi
This power bi dashboard gives insights about ecommerce product delivery and help us identify the various steps taken before delivering the product and who are responsible

# Project Overview
This project presents an interactive multi-page Logistics Dashboard built using Power BI to analyze and monitor end-to-end logistics operations.
The dashboard provides a comprehensive view of key logistics components including:
Orders & delivery performance

Hub operations

Driver performance

Fleet & vehicle management

It enables stakeholders to track KPIs, identify inefficiencies, and make data-driven decisions to optimize logistics performance.

# Project Objective

* Monitor overall logistics performance using real-time KPIs

* Identify bottlenecks in delivery operations

* Optimize hub capacity and workload distribution

* Improve driver efficiency and reduce delays

* Analyze fleet utilization and maintenance risks

* Enhance customer satisfaction through performance tracking

# Tools & Technologies Used
 
* Power BI → Data Visualization & Dashboard Development
* Power Query → Data Cleaning & Transformation
* DAX (Data Analysis Expressions) → KPI calculations & metrics
* Excel / CSV Files → Data source


# Dataset Description

* Orders Data → Order volume, delivery time, status
  
* Drivers Data → Experience, ratings, performance
  
* Vehicles Data → Vehicle type, usage, breakdowns
  
* Hub Data → Capacity, processing time, performance
  

# Dashboard Features

* Improve delivery efficiency
  
* Reduce operational delays
  
* Optimize resource utilization (drivers, hubs, vehicles)
  
* Enhance customer satisfaction
  
* Enable data-driven logistics decision-making
  
  
# Key Insights Generated

* Identified hubs operating beyond capacity, causing delays
* Detected drivers with frequent delivery delays, enabling targeted improvement
* Found correlation between driver experience and performance rating
* Highlighted vehicle models with higher breakdown rates
* Observed seasonal trends in order volume and delivery demand
* Identified inactive fleet percentage impacting operational efficiency
